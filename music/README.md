# Your own music (optional)

Reelhouse composes a fresh tune for every story by itself. If you prefer your own tracks, drop MP3 files here:

- `music/` : used for any mood
- `music/<mood>/` : used only for that mood. Moods are `playful`, `tender`, `mystery`, `adventure`, `dreamy` and `epic`.

Only use music you have the rights to.
